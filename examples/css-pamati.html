Viegls CSS ietvars ar latviskām klasēm. Balstīts uz Pico CSS filozofiju — minimāls, bet pilnīgs.

§ Krāsas

Pielāgojiet savas krāsas

Pārrakstiet CSS mainīgos :root blokā jebkurā savā stillapā:

/* Jūsu projekta CSS fails */ :root { --vitaly-pamata: #1a6b4a; /* Galvenā krāsa */ --vitaly-pamata-gaiss: #2d9c6e; --vitaly-pamata-tumss: #0f4a32; --vitaly-akcents: #e8a020; /* Izcelšanai */ --vitaly-fons: #f8f7f4; /* Lapas fons */ --vitaly-fonts: "Jūsu Fonts", serif; }
