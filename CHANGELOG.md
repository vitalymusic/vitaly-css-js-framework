# Izmaiņu vēsture

Formāts balstīts uz [Keep a Changelog](https://keepachangelog.com/lv/1.1.0/), versijas pēc [SemVer](https://semver.org/lang/lv/).

## [1.0.0] — 2026-11-07

Pirmā publiskā versija.

### Pievienots
- CSS ietvars ar latviskām klasēm: izkārtojums, tipogrāfija, pogas, formas, kartes, ziņojumi, nozīmes, tabulas, navigācija.
- Krāsu sistēma ar CSS mainīgajiem (`--vitaly-*`), automātisks tumšais režīms un `--vitaly-pamata-teksts`
  salasāmam tekstam abos režīmos.
- VitalyJS: 23 komponenti caur `data-v-*` atribūtiem (modālie logi, nolaižamā izvēlne, cilnes, akordeons,
  sakļaujams bloks, sānpanelis, toast, rīka padoms, karuselis, kopēšana, tēmas pārslēgs, gluda ritināšana,
  scrollspy, skaitļu animācija, parādīšanās ritinot, slinkā ielāde, attēlu palielinājums, parole,
  rakstzīmju skaitītājs, tabulas kārtošana, meklēšana, lasīšanas progress, poga „uz augšu”).
- JS API (`window.Vitaly`) un notikumi (`v:atverts`, `v:aizverts`, `v:cilne`, `v:tema`).
- Pilna pamācība latviski un publicēšanas instrukcija (npm, jsDelivr, cdnjs).
